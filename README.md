An original spot-the-difference game in plain static files: three hand-drawn vector scenes (Harbour Café, Night Market, Mountain Cabin), 33 differences hidden by design across three difficulty levels, a draining clock bar, miss penalties, hints that pulse the overlooked spot, pop-ring markers, a synthesized WebAudio soundtrack of blips, and a score that rewards a fast, careful eye. No libraries, no build step, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve game/ with any static file server
```
